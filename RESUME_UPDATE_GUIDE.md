## **4. HOW TO UPDATE YOUR PDF RESUME**

### Option A: Using Google Docs (Recommended for PDFs with clickable links)
1. Open your resume in Google Docs
2. Select text/links to add portfolio links
3. Insert → Link → Add the URLs above
4. File → Download → PDF Document

### Option B: Using Microsoft Word
1. Open your resume in Word
2. Insert → Link (or Ctrl+K)
3. Add the portfolio URLs
4. Save as PDF

### Option C: Using Online PDF Editor
1. Upload your PDF to https://smallpdf.com or similar
2. Add text/links to your resume
3. Download the updated PDF
